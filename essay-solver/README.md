## 💡 為什麼需要這個 Skill？

許多國考生在請通用 AI 協助解申論題時，經常面臨以下痛點：
- **空洞抽象、套話充斥**：通篇大道理卻沒有援引法條條項款、重要釋字/憲判字、大法庭裁定或具體理論命題。
- **杜撰來源與通說**：查不到出處時，常隨意冠上「實務通說認為」或自行編造不存在的裁判字號。
- **時點錯置與新舊法混淆**：面對歷屆考題時，默默套用修正後的現行法，導致答案與考試當年度的爭點背景脫節。
- **篇幅失控、無法手寫**：動輒產出長篇教科書章節，不符合考場 20～30 分鐘內必須手寫完成的結構與節奏。

**`essay-solver` 徹底解決了這些問題**：  
堅持以「考場可手寫、來源可查證、架構合邏輯」為核心原則，提供符合國考閱卷評分習慣的專業答題指引與四區塊標準輸出。

## 🚀 Antigravity 一鍵安裝方式

請依您的使用情境選擇最合適的一鍵安裝方式：

### 方案 A：Windows PowerShell 一鍵全域安裝（最快）
開啟 PowerShell，複製並執行以下單行指令，系統將自動建立目錄並將本技能安裝至 Antigravity 全域技能庫：

```powershell
$dest = "$HOME\.gemini\config\skills\essay-solver"; if (!(Test-Path $dest)) { New-Item -ItemType Directory -Path $dest -Force }; Copy-Item -Path ".\*" -Destination $dest -Recurse -Force; Write-Host "✅ essay-solver 技能已成功安裝至 Antigravity 全域目錄！" -ForegroundColor Green
```

---

### 方案 B：本機開發者軟連結（Symlink，修改即時生效）
如果您正在本機持續優化與維護此技能，推薦使用符號連結（需管理員權限或開啟開發者模式）。日後在原目錄修改 `SKILL.md`，Antigravity 會**立即同步生效**，無須重複複製：

```powershell
New-Item -ItemType SymbolicLink -Path "$HOME\.gemini\config\skills\essay-solver" -Target (Get-Location).Path -Force
```

---

### 方案 C：macOS / Linux 終端機一鍵安裝
```bash
mkdir -p "$HOME/.gemini/config/skills/essay-solver" && cp -r ./* "$HOME/.gemini/config/skills/essay-solver/" && echo "✅ essay-solver 技能已成功安裝！"
```

---

### 方案 D：從遠端 GitHub 一鍵 Clone 安裝
若您已將此技能存放於 Git Repository，可直接於任何電腦一鍵拉取至全域設定：

```bash
git clone https://github.com/<your-username>/essay-solver.git "$HOME/.gemini/config/skills/essay-solver"
```

---

### 方案 E：Antigravity 聊天框「自然語言一鍵安裝」（免開終端機）
在 Antigravity 聊天視窗中，直接將以下提示詞複製貼上：

> 「請幫我將當前目錄的 `essay-solver` 技能複製安裝到 Antigravity 全域技能目錄 (`~/.gemini/config/skills/essay-solver`)。」

## 🎯 三大專業領域解題架構

`essay-solver` 根據不同學門特性自適應調整推導脈絡：

### 1. 法政類科（民法、刑法、行政法、訴訟法等）
- **案例題**：嚴格遵循「爭點 ➔ 適用規範（法條/大法官解釋/憲判字/判例） ➔ 具體事實涵攝 ➔ 結論」之審查體系。
- **學說實務歧異**：僅在對結論有實質影響時詳述各說理由及採納立場，絕不憑空捏造學說對立。

### 2. 社會科學與管理類科（行政學、公共政策、管理學、經濟學等）
- **理論題**：交代核心命題與適用邊界，實際運用於題目情境，不以單純堆疊學者名單交差。
- **定量與經濟學**：提供模型假設、變數定義、推導公式與計算步驟，需圖形時明確交代座標軸與曲線變動方向。

### 3. 理工、資訊與技術類科（資料結構、軟體工程、電子學等）
- **技術設計題**：說明需求、假設、架構與取捨代價。
- **計算/演算法題**：提供可檢核之步驟、公式、單位或虛擬碼，並檢視邊界條件與時間/空間複雜度。

## 🎮 常用微調指令

在解題對話過程中，您可以隨時輸入以下指令快速調整產出內容：

| 快捷指令 | 效果說明 |
|---|---|
| `只給考場版` / `只要擬答` | 跳過出處與失分提醒，僅輸出考場可手寫的精鍊擬答 |
| `只列架構` | 快速產出解題大綱、爭點樹與關鍵依據，便於審題訓練 |
| `字數限 800 字` | 依指定字數重擬篇幅，調整論述深度與分配比重 |
| `依現行法重新作答` | 歷屆考題預設採考試當時法規，以此指令強制切換為現行最新法規重解 |
| `幫我修訂我的答案` | 貼上您自己寫的擬答，教練將保留原正確觀點並補充失分關鍵理由 |

## 🚫 邊界與非適用情境

為維持最高解題品質，本技能**不適用**於以下情境：
- ❌ **客觀選擇題、是非題、填空題**（請使用一般問答模式）。
- ❌ **一般抒情散文、非考試寫作**（如文學創作、心情隨筆）。
- ❌ **真實訴訟之非考試用途專業法律諮詢**（請洽詢合格執業律師）。
