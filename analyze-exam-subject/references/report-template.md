# 報告結構

預設先由 `compact_analysis.py summary` 產生統計，再撰寫報告。只載入 summary 與必要代表題，避免重讀全量題目。資料集很大時完整索引附本機連結，正文只列代表題；不要重複展開數百題。summary 是統計的唯一來源；若需核對，抽查代表題，不重算全部索引。

1. **範圍與限制**：備考科目、勾選官方科目、年度／考試、來源檔案數、去重後內容數、已解析／失敗／待確認數、分析時間與分類版本。標示完整或部分完成；檔案與頁面覆蓋率取自 summary 的 coverage。
2. **考點地圖**：主題、子主題、常見問法、相關題數、代表題來源。跨科交叉題清楚標示。
3. **命題分布**：按年度與考試分層；定義唯一題數、事件數（可判定時）、標籤命中數及百分比分母。未建立命題事件對應時寫「事件數未判定」，不要用年度分層回推。
4. **準備建議**：觀察證據與 AI 建議分開，優先順序兼顧頻率、覆蓋年份與先備關係；資料稀少時不作趨勢推論。只有來源確有配分欄位時才談配分占比。
5. **題目索引**：備考主題、官方科目、考試、年度、題號、PDF 頁碼及本機檔案連結；連結不支援頁碼時仍用文字列明頁碼。
6. **排除與待確認**：不相關題目的排除理由、不可判讀檔案、答案版本衝突、疑似重複題、未完成批次。answer_refs 與 duplicate_candidates 取自 summary／索引，衝突不要自行取最新檔名。

視覺版本另列選取頁數、文字擷取頁數、渲染頁數、已視覺核對頁數、未檢視／不可判讀／渲染失敗頁數（皆在 summary.coverage）。`pending_visual_pages` 包含尚未渲染的選取頁，`unrendered_pages` 另列渲染缺口。題目數未知時只報頁面覆蓋；連總頁數都未知時只報已知頁數與缺口，不產生百分比。圖表結論引用 PDF 頁碼及實際判讀圖片；圖片證據應指向 visual-review 實際使用的 image_sha256。未視覺核對的頁面產生待檢視清單，報告為部分完成，即使文字擷取全部成功也不例外。

所有重要結論附代表題來源。只列觀察到的結果，不把示例數字或模板內容當成分析結果。指定不同目標考試時用 `summary --target` 另存統計，不要重跑分類。
