跨瀏覽器視覺標註小工具 (Bookmarklet)

無需安裝任何 Chrome 擴充套件，只要將下方按鈕拖移到瀏覽器書籤列，就能在任何真實網站（Localhost、本地 HTML 或線上產品）點擊標註並一鍵回傳給 Antigravity。

步驟一：將此按鈕拖曳到書籤列
🎯 Antigravity 網頁標註器

💡 提示：若瀏覽器未顯示書籤列，請按快捷鍵 Ctrl + Shift + B (Mac 為 Cmd + Shift + B) 開啟。

無法拖曳？您也可以一鍵複製代碼手動建立書籤：
1

打開任一網頁

在外部 Chrome / Edge 打開您的本機網站（如 localhost:3000 或本地 HTML）或任何線上頁面。

2

點擊書籤 & 標註

點擊書籤列上的「🎯 Antigravity 網頁標註器」，畫面上會出現標註工具列，點擊任何按鈕或元件即可留下修改意見！支援 DOM 麵包屑切換外層。

3

一鍵貼回 AI 修改

點擊工具列「📋 複製修改需求」，回到 Antigravity 對話框按下 Ctrl + V，AI 就會直接更新您的程式碼！
