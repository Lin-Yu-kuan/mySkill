要在其他分頁標註，請安裝下方 Chrome 擴充功能。切換到目標網頁後，點擴充功能即可啟動；本頁示範不代表已安裝。

推薦：Chrome 擴充功能 v3.2.0

  1. 在 Chrome 網址列輸入 chrome://extensions，開啟右上角「開發人員模式」。
  2. 點「載入未封裝項目」，選擇本套件的 extension 資料夾（與 resources 同層）。
  3. 切換到你要標註的網站，點右上角拼圖 →「Frontend UI Annotator 便條紙」。可釘選到工具列。

每個分頁獨立啟動，不必回到安裝頁。成功時顯示工具列，失敗時開啟錯誤說明頁；Chrome 內建頁面無法標註。本機 HTML 需在擴充功能詳細資料開啟「允許存取檔案網址」。

只使用 activeTab 與 scripting 權限，僅在點擊時作用於目前分頁，不要求所有網站的常駐存取權限。
