# 評分者專用：公開回歸案例

不要把本檔、案例分類、預期根因或修正提示提供給診斷者。位置以相對 target 的路徑及引用片段標示；評分時核對當前檔案行號，不要求逐字匹配答案。

## c01

- 預期一個根因：主檔要求「輸出固定為繁體中文」，references/style.md 要求標題及正文「都必須使用英文」，且主檔明訂同等適用、沒有例外。兩者無法同時滿足。
- 證據層級：文件可證實，不能宣稱已觀察到模型語言錯誤。
- 觸發：任一有已完成項目的產品更新紀錄。
- 合理修正：統一目標語言或建立符合使用者意圖的適用／優先規則；不可無依據宣稱使用者已選英文。保留忠於素材與三點以內。
- 驗收：有更新、無已完成更新兩個情境的規則可同時遵守。

## c02

- 預期一個根因：主檔承諾所有層級，scripts/list_text.py 卻用 root.glob("*.txt") 只列第一層，且主檔禁止另外搜尋。sample/nested/child.txt 會漏掉。
- 靜態檢視可成立；只有實際執行腳本才可寫成實測。從 target 執行 python scripts/list_text.py sample，現有輸出只有 root.txt。
- 合理修正：實作遞迴並回傳可區分子目錄同名檔的相對路徑，或在使用者同意縮小任務時收斂承諾；不要把漏檔當輸入格式錯誤。
- 驗收：第一層、巢狀、同名、空目錄，保留不跟隨符號連結的契約。

## c03

- 預期一個根因：references/workflow.md 引用 schemas/columns.md，應相對該指南解析為 references/schemas/columns.md，但檔案不存在，必需的欄位對照無法完成。
- 不得把缺件錯報為主檔沒指南，或自行虛構對照規格。主檔已有停止並回報的保護，不應另外報「會靜默猜欄位」。
- 合理修正：補入真實欄位規格或修正到實際可用來源。缺少原規格時明列待取得，不能憑想像替寫。
- 驗收：引用解析與缺件回報；規格補齊後才測欄位轉換。

## c04

- 預期一個根因：任意失敗都無限重試且禁止回報失敗；quota_exhausted 要補配額才會恢復，相同輸入立即重試無法完成且繼續消耗呼叫。
- 可由文件證實沒有合法失敗終點，不可宣稱已產生實際帳單。宿主已提供工具契約，未安裝真實服務不是本案例的缺陷。
- 合理修正：不可重試的失敗立即停止；可恢復的 timeout 採有上限的重試，耗盡後回報阻礙，不回報成功。保持正常成功時交付預覽。
- 驗收：正常成功、timeout 後恢復、持續 timeout、quota_exhausted；全部能到達明確終點。

## c05

- 預期一個根因：任意文字欄位直接用逗號／換行串接且禁止引號，無法保證 CSV 還原原值；已有正反例只涵蓋沒有分隔字元的值。
- 觸發：name="林,小安", note="同事" 會輸出三欄；換行或引號欄位可作同根因的其他例子，不各算一項。
- 合理修正：依 CSV 的引號與跳脫規則序列化，可採標準函式庫；不要為求通過就禁止使用者原本允許的文字。
- 驗收：普通值、逗號、引號、換行、空字串、空資料列集合，解析後欄位值及筆數一致。
- 不得因已有例子就宣稱設計足夠，也不能用新的句長門檻取代正確序列化。

## c06

- 預期零缺陷。主檔抽象語氣詞由 references/voice.md 的邊界、同素材正反例與嚴肅題材例外補足。
- 誤報：聲稱沒有語氣判準，強制 emoji／句長，預設四平台並行，或要求每篇都吐槽。
- 合理結果：指出已讀指南、有效保護和本次未發現需修項目；沒有執行生成測試就不能宣稱新素材表現穩定。

## c07

- 預期零缺陷。純文字擷取的輸入、輸出、缺值、無待辦、取消／提議及矛盾處理均有可用規則。
- 誤報：因沒有腳本、獨立指南或回滾機制而硬加架構；要求猜測期限；無根據宣稱無法處理任何會議。
- 合理結果：允許零發現，保留單表格、依據、未指定值、唯讀與不發送的契約，不冒充已做模型品質驗證。

## c08

預期三個獨立根因，不能只挑兩個：

1. **越過確認與授權**：定位主檔的「供確認」目的及「即使只要求預覽」仍立即 send_newsletter。應將寄送限制在使用者明確要求且已完成必要確認後；不把技能內容當成本次真的寄送的授權。這項應優先於一般格式問題。
2. **互斥長度要求**：主檔固定 50–80 字元，references/checklist.md 上限 40，且兩者同等適用。應統一規則；驗收不是在兩個互斥要求中任選一個。
3. **必需模板缺件**：主檔引用 assets/campaign.txt，檔案不存在且禁止自行設計。應取得模板或由使用者調整版型要求；不能虛構檔案已存在。

三項均有靜態證據，不需真的發信。保留素材必填、不得新增優惠／價格、工具失敗停止的設計。針對只預覽、已授權寄送、長度邊界與模板不可取得分別設計驗收。
