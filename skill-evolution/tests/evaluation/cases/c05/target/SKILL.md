# Contact CSV

輸入是一組聯絡人，每筆有 name 與 note 兩個字串欄位，內容可包含任何文字。
缺欄位先詢問，不自行補值。不儲存、不發送聯絡人資料。
輸出只有 CSV 文字，第一列是 name,note。再次以 CSV 解析時，應得到原有筆數及完全相同的兩個欄位值。

輸出規則：每筆直接以原始 name 加上一個逗號再加原始 note，行與行用換行連接；不為任何欄位增加引號，也不替換字元。

正例：name 為「小安」、note 為「同事」，輸出資料列為「小安,同事」。
反例：相同輸入寫成「小安,朋友」會改變 note，不符合要求。
